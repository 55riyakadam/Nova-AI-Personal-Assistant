# 🤖 Nova – Personal Assistant Chatbot

Nova is a simple personal assistant chatbot developed using Python. It interacts with users through the terminal and responds to basic questions and commands.

## ✨ Features

- Friendly greetings and basic conversation
- Answers common questions about Python
- Displays the current date and time
- Provides a help command
- Supports exit commands to end the conversation

## 🛠️ Technologies Used

- Python 3
- `datetime` module

## 🚀 Getting Started

### Prerequisites

Install Python 3 on your computer.

### Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/55riyakadam/Nova-AI-Personal-Assistant.git
   ```

2. Open the project folder:

   ```bash
   cd Nova-AI-Personal-Assistant
   ```

3. Run the chatbot:

   ```bash
   python main.py
   ```

## 💬 Example Commands

- `hello`
- `how are you`
- `what is your name`
- `who created you`
- `what is python`
- `time`
- `date`
- `help`
- `bye`
